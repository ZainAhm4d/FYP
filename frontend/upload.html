What Happens on Upload

  • Type Detection

    Every column is classified as numeric, categorical, datetime, or boolean

  • Missing Value Handling

    Numeric → median fill  ·  Categorical → mode fill  ·  Datetime → forward fill

  • Duplicate Removal

    Exact-match duplicate rows are detected and removed, keeping the first occurrence

  • Categorical Normalisation

    Case standardisation, whitespace trimming, and fuzzy typo correction on text columns

  • Full Audit Trail

    Every change is recorded — view the detailed cleaning report from your Datasets page

Data Processing Pipeline

Automatically applied to every dataset you upload

File Ingestion

Type Detection

Ready to Analyse

Operation What it does Strategy / Detail
Column Type Detection Infers the data type of every column automatically Numeric, Categorical, Datetime, Boolean — heuristic + pandas dtype analysis
Missing Value Imputation Fills empty / NaN cells rather than discarding rows Numeric → median  ·  Categorical → mode (most frequent)  ·  Datetime → forward fill  ·  Columns >50% empty are dropped
Duplicate Row Removal Identifies and removes exact-match duplicate rows All columns compared; first occurrence kept
Category Normalisation Standardises text values in categorical columns Strips whitespace  ·  Title-cases values  ·  Fuzzy-matches near-duplicates (≥ 80% similarity) to correct typos
Outlier Detection Flags statistically unusual values in numeric columns IQR (Inter-Quartile Range) method; outliers are flagged in the report but not removed
Audit Report Records every transformation applied to your file Accessible from Datasets page → Report button; shows before/after row counts and per-column action log

Your original file is always preserved unchanged. The cleaned version is used only for analysis and queries.
